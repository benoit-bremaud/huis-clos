# MVP Scope - Velia

## Objectif MVP
Construire une application de chat fonctionnelle avec les fonctionnalités essentielles.

## Fonctionnalités Prioritaires (Sprint 1-3)

### Must Have (Obligatoires)
1. **Authentification**
   - Inscription email/mot de passe
   - Connexion
   - JWT + refresh tokens
   - Déconnexion

2. **Profil Utilisateur**
   - Création profil
   - Photo avatar
   - Bio
   - Modifier profil

3. **Messagerie 1-to-1**
   - Liste des conversations
   - Envoyer message texte
   - Réception temps réel
   - Marquer comme lu

4. **Contacts**
   - Rechercher utilisateur
   - Ajouter/retirer ami
   - Bloquer utilisateur

### Should Have (Secondaire)
5. **Notifications Push**
6. **Médias dans messages** (photos)
7. **Indicateur de frappe**
8. **Statut de connexion**

## Fonctionnalités Hors MVP
- Appels audio/vidéo
- Stories
- Fil d'actualité
- Chiffrement E2E
- Groupes de discussion

## Definition of Done
- Code review validé
- Tests unitaires > 80%
- Documentation mise à jour
- Déploiement test validé
